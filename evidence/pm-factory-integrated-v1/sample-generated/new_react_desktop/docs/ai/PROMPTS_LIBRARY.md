# مكتبة الأوامر الجاهزة (Universal Prompts)

> انسخ الأمر المناسب والصقه في بداية الرسالة مع أي نموذج ذكاء اصطناعي.

## 1. بدء جلسة جديدة
```text
اقرأ AI_INSTRUCTIONS.md و00_MASTER_CONTEXT.md وPRD.md وARCHITECTURE.md وTASKS.md.
لخّص فهمك في 10 أسطر، اذكر المهمة التالية من TASKS.md، واسأل عن أي غموض.
لا تبدأ التنفيذ حتى أكتب "ابدأ".
```

## 2. تنفيذ مهمة محددة
```text
نفّذ T-XXX من TASKS.md.
اتبع CODING_CONVENTIONS.md وTECH_STACK.md.
المخرجات:
1. الكود كاملًا في ملفات منفصلة.
2. اختبارات.
3. تحديث TASKS.md.
4. ملاحظات ومخاطر.
```

## 3. إضافة ميزة جديدة
```text
أريد إضافة ميزة: [الوصف].
راجع PRD.md وARCHITECTURE.md.
اقترح: مكانها في البنية، الملفات المتأثرة، معايير القبول.
انتظر موافقتي قبل التنفيذ.
```

## 4. تشخيص خطأ
```text
هذا الخطأ: [النص].
السياق: [ما كنت تفعله].
الملفات المعنية: [...].
اقترح 2-3 أسباب محتملة، ثم الحل الأبسط أولًا.
```

## 5. مراجعة كود
```text
راجع الكود التالي وفق CODING_CONVENTIONS.md وSECURITY.md.
اذكر: أخطاء، تحسينات، مخاطر أمنية، اقتراحات اختبارات.
لا تعد كتابة الكود، فقط مراجعة.
```

## 6. تلخيص جلسة طويلة
```text
لخّص آخر [N] رسالة في:
- ما تم إنجازه.
- القرارات المتخذة.
- الملفات المعدلة.
- ما لم يكتمل.
ثم اقترح تحديثات لـ TASKS.md وDECISIONS.md.
```

## 7. إنهاء الجلسة
```text
أنهِ الجلسة بتقرير:
1. ما تم.
2. ما لم يكتمل.
3. المهمة التالية.
4. تحديثات مقترحة للملفات المرجعية.
```

## 8. نقل مهمة إلى نموذج آخر (تبديل النموذج)
```text
سأكمل هذا العمل مع نموذج آخر.
لخّص كل ما يحتاجه نموذج جديد ليبدأ من نفس النقطة دون الاطلاع على المحادثة السابقة:
الحالة الحالية، القرارات المهمة غير الموثقة بعد، والمهمة التالية بالضبط.
اكتب هذا كتحديث جاهز للصق في TASKS.md وDECISIONS.md.
```
