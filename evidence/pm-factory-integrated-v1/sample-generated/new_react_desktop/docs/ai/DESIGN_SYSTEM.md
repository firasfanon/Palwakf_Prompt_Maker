# نظام التصميم

## المبادئ
1. البساطة قبل الزخرفة.
2. الوضوح قبل الجمال.
3. الاتساق قبل الابتكار.
4. الوصولية إلزامية.

## اللغة والاتجاه
- اللغة الأساسية: العربية.
- الاتجاه: RTL افتراضيًا.
- الإنجليزية: LTR داخل نفس الواجهة.
- الخطوط:
  - عربي: [IBM Plex Sans Arabic / Cairo / Tajawal]
  - إنجليزي: [Inter / system-ui]
  - الأحجام: 12 / 14 / 16 / 18 / 20 / 24 / 32 / 48

## المكونات
### الأزرار
- أحجام: sm (32px), md (40px), lg (48px).
- أنواع: primary, secondary, ghost, danger.
- حالات: default, hover, active, disabled, loading.
- لا نص أطول من 3 كلمات.

### الحقول
- الارتفاع: 40px.
- label دائمًا فوق الحقل.
- رسالة خطأ أسفل الحقل بلون error.
- placeholder للتوضيح فقط، وليس بدل label.

### الجداول
- رأس ثابت.
- صفوف متبادلة الألوان إن كانت طويلة.
- حالة فارغة إلزامية.
- حالة تحميل (skeleton).

### النوافذ المنبثقة
- إغلاق بـ Esc.
- إغلاق بالنقر خارجها.
- عرض أقصى: 600px.

## الحالات الإلزامية لكل مكون
- Loading
- Empty
- Error
- Success
- Disabled

## الوصولية (a11y)
- تباين الألوان: 4.5:1 على الأقل.
- كل صورة لها alt.
- كل حقل له label.
- التنقل بالكيبورد يعمل.
- ARIA عند الحاجة.
- لا اعتماد على اللون وحده.

## الحركات
- المدة: 150ms للتفاعلات، 300ms للانتقالات.
- Easing: ease-out.
- لا حركات مبالغ فيها.
- احترم `prefers-reduced-motion`.

## الممنوعات
- لا ألوان عشوائية خارج النظام.
- لا خطوط إضافية بدون سبب.
- لا أيقونات مختلطة من مكتبات مختلفة.
- لا ظلال ثقيلة.
- لا استخدام emojis في واجهة الإنتاج.
