## اختبارات الانحدار الدقيقة (سلبية)

- **R7** (F07): وحدة `writeAll` (كتابة بايت واحد لكل استدعاء ← محتوى مطابق متعدد البايتات؛ ستة أعداد زائفة ← رمز خطأ محدد لكل منها)؛
  تشغيل كامل بكتابة بايت واحد لكل استدعاء ← `COMPLETED` و`verify=OK`؛ صفر بايت لسطر `CHILD_EVENT` ← خروج 8،
  `EVENT_WRITE_FAILED:ZERO_WRITE` وسلسلة `basis` حرفية، والأحداث بالضبط `RUN_START, PREFLIGHT, CHILD_SPAWN`، والعملية الفرعية مقتولة؛
  نصف السطر ثم توقف ← استدعاءان بالضبط، `TRUNCATED_TAIL`، 3 أحداث صالحة، والاستعادة `UNKNOWN`؛ عدد مبالغ فيه ← `BAD_WRITE_COUNT`
  دون تشغيل العملية الفرعية؛ توقف كتابة `result.json` ← لا `result.json` ولا ملف tmp؛ فشل إغلاق سجل الأحداث بعد `RUN_END=COMPLETED`
  ← `UNKNOWN`/8، والتزوير إلى `COMPLETED` مع إعادة حساب البصمات يُكشف؛ فشل إغلاق tmp لـ `run.json` وإغلاق مقبض المجلد ← خروج 8 دون تشغيل.
- **R8** (F08): مجموعة القيم الحساسة بالضبط؛ 11 قيمة مدفونة يُحذف كل منها بحقل واحد بالضبط؛ الحد `STEP_XYZ` يبقى؛ القيم السليمة لا تتأثر؛
  سطر مختلط يُحذف منه حقلان بالضبط؛ تشغيل طرفي ببيئة ثابتة ← حدث وحيد سليم و`child_fields_dropped = 5` ولا أثر للأسرار.
