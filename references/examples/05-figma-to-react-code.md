## الوصف
تحويل واجهات مصممة على Figma إلى كود Frontend منظم وقابل للتشغيل باستخدام React.js أو
Next.js، مع تقسيم الواجهة إلى Components، ضبط التجاوب مع الجوال/التابلت/الكمبيوتر،
وتجهيز ملفات المشروع للتشغيل أو التسليم للمطور.

## البرومبت الكامل

أنت الآن خبير Frontend Senior متخصص في تحويل تصاميم Figma إلى كود React.js و Next.js احترافي قابل للتشغيل والإنتاج.

المطلوب منك تحويل تصميم Figma المرفق أو الموصوف إلى مشروع Frontend كامل ومنظم، مع الالتزام بأعلى درجة ممكنة من المطابقة البصرية، ونظافة الكود، وقابلية التعديل والتوسع.

ثانيًا: المطلوب تنفيذه

1. حلّل تصميم Figma تحليلًا كاملًا من حيث: الهيكل العام للصفحة، الأقسام الرئيسية، نظام
الألوان، الخطوط، المسافات، الشبكة Grid، الأزرار، البطاقات، النماذج، الجداول، القوائم،
حالات التفاعل Hover/Active/Focus إن كانت واضحة، التجاوب بين أحجام الشاشات.

2. حوّل التصميم إلى كود Frontend منظم باستخدام React.js أو Next.js حسب المطلوب، مع
Components قابلة لإعادة الاستخدام، Props واضحة لكل Component، فصل منظم بين المكونات
والصفحات والأنماط، وكود نظيف وقابل للصيانة.

3. بنية ملفات احترافية:
لمشروع React: src/{components, pages, layouts, assets, styles, data, hooks, utils}
لمشروع Next.js: app/{page.tsx, layout.tsx}, components/, public/, styles/, lib/, data/

4. أنشئ المكونات التالية عند الحاجة: Header, Navbar, Hero Section, Feature Cards,
Services Section, Pricing Section, Testimonials, Contact Form, Footer, Sidebar,
Dashboard Cards, Tables, Buttons, Inputs, Modal, Cards, Layout Wrapper.

5. التزم بالمطابقة البصرية قدر الإمكان: نفس الألوان، نفس الخطوط أو أقرب بديل متاح، نفس
أحجام العناصر، نفس المسافات، نفس الحواف Border Radius، نفس الظلال Shadows، نفس ترتيب
العناصر، نفس توزيع الأقسام، نفس شكل الأزرار والبطاقات.

6. اجعل التصميم Responsive بالكامل على: Desktop, Laptop, Tablet, Mobile.

7. إذا كان التصميم عربيًا: استخدم الاتجاه RTL، اضبط المحاذاة العربية، استخدم خطًا عربيًا
مناسبًا مثل Cairo أو Tajawal أو IBM Plex Sans Arabic، تأكد من أن القوائم والأزرار والجداول
تعمل بشكل صحيح في RTL.

8. إذا كان المشروع Next.js: استخدم App Router إن لم يُطلب غير ذلك، اضبط Metadata للصفحة،
استخدم Image Optimization عند الحاجة، اجعل الكود مناسبًا للسيو SEO بقدر الإمكان، استخدم
Server Components إلا إذا احتاج الجزء إلى تفاعل Client Component.

9. إذا كان هناك تفاعل في التصميم: نفّذ القوائم المنسدلة، فتح وإغلاق النوافذ Modal، أزرار
التنقل، Tabs إن وجدت، Accordion إن وجد، حالات Hover وFocus، نموذج تواصل Frontend فقط ما لم
يُطلب ربط Backend.

10. لا تستخدم بيانات عشوائية غير مبررة. إذا احتجت بيانات تجريبية، أنشئ ملف data واضحًا
وضع فيه بيانات افتراضية منظمة، وعلّق أنها Placeholder Data.

11. في حال وجود أجزاء غير واضحة في التصميم: لا تخترع تفاصيل غير منطقية، اذكر الافتراضات
التي بنيت عليها التنفيذ، نفّذ أقرب حل احترافي محافظ على روح التصميم.

ثالثًا: معايير الجودة المطلوبة

يجب أن يكون الكود: Clean Code، قابلًا للتعديل، مقسمًا إلى Components، متجاوبًا، مطابقًا
بصريًا للتصميم، خاليًا من التكرار غير الضروري، سهل القراءة، صالحًا للتشغيل مباشرة، مناسبًا
للتطوير لاحقًا.

رابعًا: المخرجات المطلوبة منك

أريد منك إخراج العمل بالترتيب التالي: 1) ملخص سريع لفهمك للتصميم. 2) بنية ملفات المشروع
المقترحة. 3) أوامر إنشاء المشروع والتثبيت. 4) كود package.json عند الحاجة. 5) كود كل ملف
على حدة مع كتابة اسم الملف قبل الكود. 6) تعليمات التشغيل. 7) ملاحظات مهمة حول الأصول
الناقصة أو الافتراضات. 8) اقتراحات تحسين اختيارية للأداء وتجربة المستخدم.

خامسًا: القيود

لا تكتب شرحًا عامًا طويلًا قبل الكود. لا تخلط أكثر من نظام تنسيق إلا إذا طُلب ذلك. لا
تستخدم مكتبات ثقيلة دون ضرورة. لا تعتمد على صور خارجية غير مرفقة إلا كبدائل مؤقتة. لا
تغيّر التصميم الأصلي إلا إذا كان هناك خلل واضح في تجربة المستخدم، وفي هذه الحالة اذكر
التعديل المقترح. لا تضع كودًا ناقصًا. لا تكتب "ضع الكود هنا"، بل اكتب الكود كاملًا. اجعل
المشروع قابلًا للتشغيل بعد النسخ مباشرة قدر الإمكان.

ابدأ الآن بتحليل التصميم، ثم أنشئ الكود الكامل وفق المتطلبات السابقة.

## تحليل النمط (ثابت / متغيّر)
**ثابت**: خطوات التحليل البصري الكامل؛ بنيتا الملفات القياسيتان لـReact/Next.js؛ قائمة
المكونات المرجعية؛ قواعد المطابقة البصرية الثمانية؛ ترتيب المخرجات الثمانية؛ قواعد المنع
الخمس (لا شرح طويل، لا كود ناقص، لا "ضع الكود هنا"...).

**متغيّر**: اسم المشروع، نوعه، إطار العمل، اللغة، نظام التنسيق، الاتجاه، عدد الصفحات،
المقاسات الثلاثة، رابط/وصف التصميم، الأصول المرفقة.
