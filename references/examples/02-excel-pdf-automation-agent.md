## الوصف
وكيل ذكي يستلم ملفات Excel أو PDF وينفّذ تلقائيًا سلسلة أعمال بدل القيام بها يدويًا:
قراءة وتحليل الجداول، تنظيف البيانات، دمج/تقسيم الملفات، اكتشاف التكرار والقيم الناقصة،
إنشاء تقارير ولوحات Dashboard، استخراج جداول من PDF وتحويلها، معالجة مجلد كامل دفعة واحدة.

مثال عملي: مجلد فيه 120 فاتورة PDF + ملف Excel رئيسي → الوكيل يقرأ الفواتير، يستخرج
رقم الفاتورة والتاريخ والمبلغ والمورد، يدخلها في Excel، يكشف التكرار، يحسب الإجماليات،
وينشئ Dashboard وتقرير PDF نهائي.

## خطوات التنفيذ للمبتدئ (كما وردت في المصدر)
1. أنشئ مجلدًا جديدًا (مثل Excel-PDF-Automation-Agent) بداخله ثلاثة مجلدات فرعية:
   Excel (ملفات أصلية) / PDF (ملفات أصلية) / Output (النتائج).
2. ضع ملفات تجريبية داخل كل مجلد.
3. افتح المشروع بـ Codex وأعطه البرومبت أدناه — لا تكتب كودًا بنفسك.
4. اطلب واجهة بسيطة: رفع ملفات → اختيار العملية → تشغيل → معاينة → تنزيل.
5. اجعل Codex يختبر البرنامج على الملفات التجريبية.
6. بعد نجاح النسخة الأولى، أضف نظام Workflow متسلسل (PDF → Extract → Clean → Merge →
   Analyze → Dashboard → Report) ليتحول من برنامج إلى وكيل أتمتة حقيقي.

## البرومبت الكامل

أريد منك بناء تطبيق احترافي باسم:
Excel & PDF Automation Agent
وكيل أتمتة معالجة ملفات Excel وPDF

الهدف:
إنشاء نظام ذكي يسمح للمستخدم برفع ملفات Excel وPDF ثم تنفيذ عمليات أتمتة متعددة عليها دون الحاجة إلى معرفة برمجية.

يجب أن يحتوي النظام على واجهة استخدام سهلة باللغة العربية مع دعم اللغة الإنجليزية.

الوظائف الأساسية:
1. رفع ملف واحد أو عدة ملفات Excel. 2. رفع ملف واحد أو عدة ملفات PDF. 3. قراءة ملفات
Excel وتحليل أوراق العمل. 4. تنظيف البيانات. 5. حذف الصفوف الفارغة. 6. اكتشاف البيانات
المكررة. 7. اكتشاف القيم الناقصة. 8. توحيد أسماء الأعمدة. 9. توحيد صيغ التاريخ والأرقام.
10. دمج عدة ملفات Excel. 11. تقسيم ملف Excel حسب قيمة عمود يختاره المستخدم. 12. استخراج
الجداول من ملفات PDF. 13. تحويل الجداول المستخرجة من PDF إلى Excel. 14. استخراج بيانات
محددة من ملفات PDF. 15. معالجة عدة ملفات PDF دفعة واحدة. 16. إنشاء ملف Excel موحد من
البيانات المستخرجة. 17. إجراء إحصاءات وصفية على البيانات. 18. إنشاء رسوم بيانية تلقائيًا.
19. إنشاء Dashboard مبسط. 20. إنشاء تقرير PDF نهائي يحتوي على النتائج والجداول والرسوم.

أريد نظام Workflow يسمح للمستخدم بإنشاء سلسلة عمليات مثل:
PDF ↓ Extract Data ↓ Clean Data ↓ Merge Excel ↓ Validate ↓ Analyze ↓ Dashboard ↓ PDF Report

أنشئ وكلاء متخصصين:
Orchestrator Agent, PDF Processing Agent, Excel Processing Agent, Data Cleaning Agent,
Validation Agent, Analytics Agent, Visualization Agent, Report Agent.

يجب أن يقوم Orchestrator Agent بتحليل طلب المستخدم ثم تحديد الوكلاء والعمليات المطلوبة.

أضف صفحة تعرض: الملفات المدخلة، العمليات الحالية، نسبة تقدم التنفيذ، الأخطاء المكتشفة،
الملفات الناتجة.

أنشئ سجل Audit Log لجميع العمليات.

لا تعدل الملفات الأصلية. أنشئ جميع النتائج في مجلد Output.

أضف ميزة Preview قبل حفظ النتائج.

اجعل النظام يتحقق من النتائج قبل تسليمها للمستخدم.

إذا وجد خطأ في ملف، لا توقف معالجة باقي الملفات، بل سجل الخطأ واستمر في التنفيذ.

أنشئ المشروع كاملًا مع بنية ملفات منظمة. ثبّت المكتبات المطلوبة. شغّل المشروع. أنشئ
بيانات وملفات تجريبية. اختبر جميع الوظائف. إذا ظهر أي خطأ أصلحه تلقائيًا.

لا تكتفِ بكتابة الكود.

## تحليل النمط (ثابت / متغيّر)
**ثابت**: بنية الوكلاء الثمانية (Orchestrator + 7 متخصصين)؛ مبدأ عدم تعديل الملفات
الأصلية؛ سجل Audit Log إلزامي؛ Preview قبل الحفظ؛ الاستمرار عند الخطأ بدل التوقف الكامل؛
قائمة الوظائف العشرين الأساسية؛ مطالبة الأداة بعدم الاكتفاء بكتابة الكود (تشغيل + اختبار
+ إصلاح ذاتي).

**متغيّر**: نوع الملفات الفعلية المرفوعة؛ سلسلة الـWorkflow المحددة لكل حالة استخدام؛
العمليات المختارة من القائمة حسب حاجة المستخدم الفعلية.
